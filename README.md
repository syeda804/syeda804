## 🚀 Featured Project — EventHub

> A full-stack, multi-role event management platform built with **Laravel 10**, **MySQL**, **Bootstrap 5**, **Stripe**, and **Groq AI**.

| Feature | Description |
|---|---|
| 🤖 AI Event Planner | Smart suggestions for budget, vendors & venues |
| ✍️ AI Description Generator | Auto-generates event descriptions |

| 🎟️ QR Ticketing | QR-based ticket generation & scanning |
